# 검토지 — 쪽파에 닿는 것만 (⑤ 권고: 셋만)

발행자가 **한 줄씩** 답하는 자리다. 답은 `맞다` / `아니다(→ 무엇)` / `모르겠다` 중 하나면 된다.
답이 들어오면 세션이 정본(CSV · JSON)에 반영하고 이 문서는 "반영됨"으로 닫는다.
