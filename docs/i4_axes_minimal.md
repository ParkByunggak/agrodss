# I-4 — 격자가 참조하는 축 최소 고정

**무엇을 지키려는가**: 격자 스키마(M-4)를 고정하려면 칸의 "판정 축 / 금지 축"이 가리킬
이름이 있어야 한다. 축 전부를 지금 수렴시키는 것이 아니라(U-6 — 다섯 작목 연속으로
늘었다), **격자 칸이 참조하는 축의 이름과 성격만** 고정한다. 값·데이터·해상도는 비어 있어도 된다.

작성 2026-09-18. 대장 I-4. 근거: 평가서 §4 #4 — M5 가 N 축 수렴에 의존.

## 0. 축과 칸 값을 가른다

```
축(axis)     런타임 입력 — 1층에서 들어오고 시각·출처·해상도를 갖는다      예: 기온
칸 값(cell)  격자 지식 — 작목·단계에 고정된 상수                           예: 광 요구도(양지)
```

트리 E 의 "광 셋"은 **칸 값**이다(작목 속성). 축이 아니다. 축은 그 칸 값과 비교되는
런타임 값(일장 · 조도 없음)이다. 이 구분을 안 하면 격자에 기상값이 들어가거나 축에
작목 상수가 들어간다.

12개. **금지 축**으로만 등장하는 것도 이름은 여기 둔다 — `humidity_air`(대기 습도)는 수분
판단의 금지 축이자 병해충 판단의 필요 축 후보다. 금지는 **판단 단위로** 선언한다(전역 아님).

| id | 이름 | 성격 | 지금 상태 |
|---|---|---|---|
| `humidity_air` | 대기 습도 | 관측 | 수분 칸: 금지 / 병해충 칸: 후보(안 열림) |

**안 하기로 한 것(검사로 고정 — 2026-09-19 코드 평가 §1-1)**: 평년값(`reference.climate_normal`, `ingest/kma.fetch_normals`)은
스키마와 수집기가 있으나 **호출자를 두지 않는다**. 지금 격자 칸 중 평년을 판정 축으로 선언한 칸이 없다(§3 규칙 — 칸이 선언할 때만
축을 연다). 열 때는 칸 선언 · 이 표의 축 한 줄 · `judge/run.gather_*` 배선 · 대장 등재를 함께 한다. `tests/test_joint_consistency.py`
가 "호출자 0 + 이 문단 존재"를 본다 — 참조 0 이 '빠뜨린 것'으로 읽히지 않게.

## 2. 등록만 되고 데이터가 없는 축을 두는 이유

트리 E: *"데이터가 없어도 축은 등록돼야 '없어서 못 한다'를 말할 수 있다."* 12개 중
데이터가 있는 것은 `daylength` 하나(계산)다. 나머지는 I-1 §2-4 **판단 불가(데이터)** 의
`missing` 에 이름으로 나타난다. 이름이 없으면 "무엇이 없는지"를 말할 수 없다.

## 3. 축을 늘리는 규칙 (C 에서 옮겨 옴)

```
격자 칸이 그 축을 판정/금지 축으로 선언할 때만 추가한다
칸 값으로 표현되는 것은 축이 아니다
추가 시 이 표에 한 줄 + 대장에 등재(칸 2)
```

전염원 근접성(병해충 ①)은 다농가 이전에는 데이터가 원리적으로 없으므로 **지금 등록하지
않는다** — 등록 시점은 단계 5(마을 단위).

## 4. 검사 (M-4)

- 격자 칸의 판정/금지 축 선언이 이 표의 id 밖을 가리키면 실패(거부).
- 이 표의 축 중 어느 칸도 참조하지 않는 것이 있으면 경고(소비자 0 — 이름만 남은 축).
