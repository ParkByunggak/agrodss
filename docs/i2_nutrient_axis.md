# I-2 — 양분 · 토양화학 축 등록

**무엇을 지키려는가**: 예정지 관리(B3)와 시비 판단이 **축 없이** 서 있지 않게 한다. 축이
등록돼야 "검정값이 없어서 판단 불가"를 말할 수 있고, 대표값을 필지값처럼 쓰는 사고를
해상도 표기로 막을 수 있다.

작성 2026-09-18. 대장 I-2. 근거: 평가서 §4 #2 — 트리 E 가 "축이 빠지는 세 경로 ①(결정이
등록 안 됨)"을 스스로 재현했다.

## 0. 가정

| 가정 | 영향 |
|---|---|
| 첫 농가의 필지 검정 여부 미확인 | 첫 산출은 읍면동 대표값 해상도일 수 있다 — 조건 동반 필수 |
| 인증 유형 미확인 | 유기이면 화학비료 처방 자체가 해당 없음 |

## 1. 축 정의

| 항목 | 값 |
|---|---|
| 축 이름 | `soil_chem` (토양화학) |
| 성격(E 3분류) | **관측** — 검정으로 확보. 계산 아님, 추정 아님 |
| 구성 항목 | pH · EC · 유기물 · 유효인산 · 치환성 K/Ca/Mg · 석회소요량 · (토성은 필지 고정 정보에 있음 — 여기 아님) |
| 관측 시각 | 검정 채취일. **유효기간은 격자 칸이 정한다**(작목·작기별로 다르다 — 여기 상수로 박지 않는다) |
| 출처 | 필지 검정 성적서(농가 제출) / 공공 토양 DB 읍면동 대표값 |
| 해상도 | **두 수준** — 아래 |

### 해상도 두 수준

| 수준 | 뜻 | 신뢰 | 산출 조건 |
|---|---|---|---|
| `parcel` | 이 필지의 검정값 | 관측 등급 | 그대로 |
| `district` | 읍면동 대표 필지의 값 | 관측 등급이지만 **해상도 낮음** | 산출에 *"읍면동 대표값 기준"* 조건이 **반드시** 붙는다 |

`district` 는 대리값이 아니다 — 해상도가 낮은 **사실**이다. 그래서 G3(대리값 금지)에
걸리지 않지만, 조건 없이 필지값처럼 실으면 **"부분 전달이 전체 전달보다 나쁘다"**(VELA
N-149 발행자 판정)가 된다. 조건 필드를 떼는 소비자는 결함이다.

## 2. 파생(2층)과 판단(3층)

```
1층  검정값(soil_chem, 해상도 표기) · 작목 · 목표 수량
2층  시비 처방량 = 작목 표준 요구량 − 토양 잔존 보정        ← 공공 처방 기준을 정본으로
     해상도가 district 면 파생값에도 district 표기가 전파된다
3층  "예정지 관리" 결정: 필요 축 = soil_chem · 작목 · 인증 유형
     금지 축 = 전년 시비량 단독(기록이지 축이 아니다 — 참고로만)
```

2층 규칙: **원 사실의 해상도가 낮으면 파생값도 낮다.** 파생에서 해상도가 올라가는 일은 없다.

## 3. 인증 갈래 — 산출 레벨 1회

유기 인증(법정 또는 몰 기준)이면 화학비료 처방은 **해당 없음**(I-1 §2-6)이고, 대신 유기
자재 갈래가 선다. 이 갈래를 **경로마다 넣지 않는다** — VELA 경험: 초입 pop 이 뒤의 주입을
못 막았고(N-97), 한쪽 함수만 막아 다른 쪽으로 샜고(N-136), 관문에 `organic` 이 안
도착하는 호출부가 남았다(N-147). 처방은 **산출 레벨 말미 1회** + **입력 도착 전수 래칫**.

## 4. 입력 5종과의 연결 (I-3)

| 입력형 | 이 축에서 |
|---|---|
| 필지 고정 | 토성 · 인증 유형 · 관수 (보정 재료) |
| 사건 | 시비 기록(자재 · 양 · 시각) — 되먹임 재료, 축 아님 |
| 관찰 | (없음) — 양분 결핍 증상 관찰은 별개 축 후보, 지금 안 연다 |
| 계획 | 목표 수량(있으면) |
| 결정 | 처방 채택/불이행 + 사유 |

## 5. 데이터 확보 상태 (2026-09-18)

```
축 등록     완료 (이 문서)
데이터      없음 — 첫 농가 미정. 공공 원천 키 미발급(D-5)
```

축 등록 ≠ 데이터 확보(트리 E). 이 상태에서 예정지 관리 결정을 물으면 산출은
**판단 불가(데이터)** 이고 `missing = [soil_chem]`, 채울 수 있는 자 = 농가(검정 제출) 또는
외부 원천(대표값).

## 6. 검사 (M-4 · M-5)

- 격자 칸 "예정지 관리"의 필요 축에 `soil_chem` 이 선언돼 있다.
- `district` 해상도 입력에 대한 산출 봉투의 `inputs` 에 해상도가 살아 있다(조건 탈락 검사).
- 유기 인증 표본에 화학비료 처방이 나오면 실패(거부) / 관행 표본에 처방이 나온다(통과).
