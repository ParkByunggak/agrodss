# M-11 — 몰 MVP 목업: 영상 상세페이지 (`mall/product.py` · `/mall/<재배 단위>`)

**무엇을 지키려는가**: 발행자 대원칙 *"몰은 현장의 영상을 상세페이지로 대체한다"*. 상품 키는
재배 단위(몰-B)이고, 소비자가 보는 것은 **촬영 칸의 시계열**(몰-C)이다. DSS 에서 몰로 가는 것은
몰-H 허용 목록뿐이며, 필지 상세는 어떤 경로로도 가지 않는다.

작성 2026-09-19. 대장 M-11(목업 완료 · MVP 는 봄 작기 D-8 검토 뒤). 근거: 몰 트리 B · C · F · G · H.

## 1. 뷰가 담는 것 / 안 담는 것

| 담는다 | 출처 | 안 담는다 | 왜 |
|---|---|---|---|
| 상품명(작목 · 작기) · 상태 · 기준점 후 N일 | 재배 단위 등록부 | 주소 · PNU · 좌표 · 검정값 | 몰-H · I-5 PII |
| 촬영 칸 시계열(칸 · 장면 · 창 · 상태 · 클립) | 격자 capture + 영상 공개 뷰 | GPS(있음/없음도 안 싣는다) · 파일 경로 · 해시 | 공개 뷰에서 뺀다 |
| 인증 표기 | 필지 `cert_legal` 확인 시만 | 주장만 있는 '유기' | 몰-F: 인증서 없이 표기 금지 |
| 판정(판정 + 관측일 + 기준) | `consumer_visible=True` 이고 판단함인 봉투만 | 판단 불가 · 해당 없음 · 원본 값 · 영상 판독 | 몰-G · G2 |
| 예약 판매 · 수량 | 자리만 — "없음(D-3 · 몰-N)" | 지어낸 수량 | 대리값 금지 |

`assert_public()` 이 뷰를 **재귀로** 걷어 금지 키(PII · soil_chem · values · raw · file · sha256 · gps …)가
있으면 올린다 — 조용히 빼지 않는다. 검사가 좌표 있는 영상을 넣고 뷰 문자열 전체에서 좌표 · 주소 ·
해시가 안 보이는 것을 본다.

## 2. 촬영 칸 상태

```
촬영됨          창 안에 클립이 있다
촬영 예정       창이 아직 안 열렸다
촬영 창 열림    지금 찍을 수 있다(채팅 오른쪽 '찍을 장면'과 같은 칸)
미촬영(창 지남) 상세페이지에 빈 칸으로 남는다 — 연속성이 상품이라 빈 칸도 사실이다
```

첫 농가(T+25): 칸 1·2 미촬영, 칸 3 창 열림, 칸 4·5 예정. 영상 원장에 클립이 들어오면 새로고침에 바로 뜬다.

## 3. 남은 것(MVP 로 가려면)

- 외부 영상 저장 · 트랜스코딩 · 스트리밍(CDN) — 자체 구축 금지 영역(몰-C ●). 목업은 메타만 보여 준다.
- 노출 판정 D-2 · 예약 판매 D-3 · 인증 유형 등록(몰-F 2단계) — 발행자 결정.
- 정산 → 사건 변환은 M-3 에서 이미 서 있다(`boundary.settlement_to_events`). 몰 정산 화면이 그것을 부르면 된다.
