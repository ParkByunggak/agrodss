# agrodss 작업대장 (정본 — 하나뿐이다)

개설 2026-09-18. 진도 관리의 정본은 이 파일 하나다. 마일스톤 문서는 **계획**, 이 대장은
**상태**다. 둘이 어긋나면 대장이 맞다(계획은 그때 고친다).

## 대장 규칙 (VELA 대장에서 물려받음 — 실패로 배운 것만)

1. **항목 삭제 금지.** 완료·폐기도 상태로 남긴다(VELA v103 백로그 소실 · rev.1 D-16 압축 전례).
2. **등재 문턱** — 기준은 하나: *"지금 안 고치면 무슨 일이 나는가."*

   | 칸 | 대상 | 처리 |
   |---|---|---|
   | 1 | 안전 · 실사용 직격 · 관문 차단 | 즉시 등재 |
   | 2 | 구조적 위험(갈라지면 난다) | 등재 + 회수 대기 |
   | 3 | 위험 없는 관찰 | **등재하지 않는다** — 핸드오버 부록에만 |

   3칸을 등재하면 대장이 붇고 신호를 잃는다(VELA 2026-08-28: 해소 15 · 신규 10 · 미결 14→14).
3. **근거란은 측정 시점 기록이다.** 실측을 적을 때 날짜를 함께 적는다. 재료로 쓰기 전에 다시 잰다.
4. **상태 열 값**: `대기` · `진행` · `완료` · `보류` · `폐기`. 완료에는 검증 커밋 해시를 적는다.
5. **순증 > 0 이 3주기 연속이면 범위를 조정한다** — 발견이 해소를 따라잡은 것이다.
6. **ID 접두**: `M-` 마일스톤 · `D-` 발행자 결정 · `I-` 즉시 처방 · `U-` 미해결 · `R-` 규율 위반/회귀.
7. 세션 마감 시 **이 파일의 상태 열을 갱신한 뒤** 완료를 보고한다. 갱신 안 한 완료 보고는 미완이다.
