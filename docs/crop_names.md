# 작목 이름 사전 — 정본명 · 이명 · 관계 (정본: `data/crop_names.csv`)

**이 문서는 생성물이다.** 고치려면 CSV 를 고치고 `python scripts/build_crop_axes_doc.py` 를 돌린다.

**원칙 (발행자 2026-09-18)**: 이름 혼동은 격자보다 먼저 정리한다. 현장은 사투리를 쓴다 — 사전은 열린 목록이고, 모르는 이름은 추측하지 않는다(`names/resolve.py` 가 `unknown` 을 돌려주고 채집 대상이 된다).

| 관계 | 뜻 | 정규화 |
|---|---|---|
| 동일 | 같은 식물, 이름만 다름 | 이명 → 정본명. **격자 단위 하나** |
| 용도구분 | 같은 종, 용도(찰성·사료·잎/종실)가 달라 구분 | 각자 정본 — 격자 단위 별개 |
| 품종군 | 같은 종의 품종군 | 각자 정본(또는 품종 보정) |
| 부산물 | 작목의 잎·순·수피 등 | 격자는 모체 작목 |
| 다른종(혼동주의) | 다른 종인데 현장에서 섞어 부름 | 둘 다 정본 — 되묻기 문구에 상대를 붙인다 |
| 모호 | 통칭 — 하나로 정할 수 없음 | **되묻기** (대표값 강제 금지) |
