# M-13 — Claude 형식 채팅 화면 · 채팅 목록 = 재배 단위 · 채팅 → 영농일지

**무엇을 지키려는가**: 농가가 적는 곳은 하나(채팅)이고, 시스템은 거기서 **분류해 제안**하되
**대신 적지 않는다**. 원장은 확인을 거친 것만 받는다(대리값 금지). 영농일지는 새 원장이 아니라
원장을 날짜로 펼친 것이다(두 벌 금지).

작성 2026-09-19. 대장 M-13. 근거: 발행자 2026-09-19 *"frontend 디자인은 claude 형식으로 하되,
채팅목록은 등록된 작목이 있으면 해당 작목이 채팅목록이 되며, 신설되는 목록은 작목을 추가하려
하거나 계획이 있을 때 해당 목록을 생성하는 것으로 한다. 그리고 영농일지도 채팅을 통해 얻어 지는
정보를 분류해서 영농일지가 작성이 될 수 있도록 한다"* · I-3 §3(질의 자체가 관찰) · I-5 §5(화면은
원장을 직접 열지 않는다).

## 1. 화면 (`frontend/chat_pages.py` · `frontend/serve.py`)

```
왼쪽   채팅 목록 = 재배 단위(data/subjects.json)   상태 pill(계획 / 재배 중) · 기준점 후 N일
       ＋ 새 채팅 → 작목 · 작기 · 상태 · 기준점(선택) · 인증(선택) · 필지
       화면(개선 · 판단 · 영상 · 사건) · 문서 목차
가운데 대화 — 내 발화(오른쪽 말풍선) · 시스템 답(왼쪽) · 발화 아래 **초안 카드**(확인 → 원장)
오른쪽 오늘(찍을 장면 · 미확인 초안 · 필지 입력 대기) · 판단(종류가 먼저) · 영농일지 최근 8
```

경로: `/` → 첫 목록으로 · `/c/new` · `/c/<id>` · `/c/<id>/send|confirm|choose` · `/diary/<id>` ·
`/improve`(개선 요구 · 개선 항목 채택/거부 · 자율진화 한 바퀴) · 기존 `/judge` `/media` `/events` `/doc/…`.

## 2. 새 목록은 언제 생기나

작목을 추가하거나 계획이 생길 때 — `ingest/subjects.add`. 작목 이름은 사전(`names/resolve`)을
거친다: 정본·이명이면 정본명으로, **모호하면 되묻고, 없으면 등재를 청한다**(추측 금지, U-14).
파종 전이면 `status=계획`, `anchor` 없음. 격자 단위는 있으면 붙고 없으면 안 붙는다(판단 불가(지식)).
채팅에서 파종·정식 사건을 확인하면 기준점이 들어가고 `재배 중`이 된다.

## 3. 분류 (`ingest/chat.classify` — 2층, 제안만)

| 순서 | 어휘 | 초안 |
|---|---|---|
| 1 | `?` · 언제 · 얼마나 · 할까 · 어떻게 … | 질문 → 3층 봉투로 답(수확 시기 · 위험 경보 · 자재 · 계획 대 실제). 대응 결정이 없으면 **판단 불가(지식)** |
| 2 | 틀렸 · 고쳐 · 바꿔 · 개선 · 불편 · 너무 넓 … | 개선 요구 → `feedback.request`(J) |
| 3 | 려고 · 예정 · 계획 · 겠다 … (+납품·출하면 납품 계획일) | 계획 → `plan.farmer` / `plan.target_date` |
| 4 | 피해 어휘(서리 맞 · 얼었 · 썩었 · 벌레 먹 · 병 걸 · 피해) | 피해 사건 → `event` type=피해, `risk`=갈래(서리 · 부패 · 해충 · 병). 갈래 미상이면 확인 화면이 묻는다(U-16) |
| 5 | 사건 어휘(심었 · 뿌렸 · 물 줬 · 풀 뽑 · 트랩 · 캤 · 보냈 …) | 사건 → `event`(종류 16) |
| 6 | 보인다 · 누렇 · 시들 · 벌레 · 싹 · 줄기 · 왕성 · 모습 · 상태 … | 관찰 → `observation.note` (발행자 첫 발화 2026-09-19 로 생육 서술 어휘 확장) |
| — | 아무것도 안 걸림 | **분류 안 됨** — 사람이 종류를 고른다(추측으로 적지 않는다) |

날짜: `2026-09-20` · `9월 20일` · `어제/그저께/내일` · `3일 전`. **날짜 없는 사건·계획은 확인 화면이
날짜를 묻고, 없으면 원장에 안 들어간다.** 관찰만 "오늘 본 것"으로 제안한다(확인에서 고친다).

LLM 은 여기 없다. 규칙 분류가 못 나누면 못 나눴다고 말한다 — 어휘 목록을 늘리는 것은 개선
항목(확장)으로 사람이 채택한다.

## 4. 영농일지 (`ingest/chat.diary`)

사건 · 관찰 · 계획 · 불이행 사유 · 영상 원장을 날짜 내림차순으로 펼친다. 채팅에서 온 것은
`chat_ref` 로 표시. 미확인 초안은 일지에 **안 들어간다**(확인 전은 원장이 아니다).
