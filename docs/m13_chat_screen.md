# M-13 — Claude 형식 채팅 화면 · 채팅 목록 = 재배 단위 · 채팅 → 영농일지

**무엇을 지키려는가**: 농가가 적는 곳은 하나(채팅)이고, 시스템은 거기서 **분류해 제안**하되
**대신 적지 않는다**. 원장은 확인을 거친 것만 받는다(대리값 금지). 영농일지는 새 원장이 아니라
원장을 날짜로 펼친 것이다(두 벌 금지).

작성 2026-09-19. 대장 M-13. 근거: 발행자 2026-09-19 *"frontend 디자인은 claude 형식으로 하되,
채팅목록은 등록된 작목이 있으면 해당 작목이 채팅목록이 되며, 신설되는 목록은 작목을 추가하려
하거나 계획이 있을 때 해당 목록을 생성하는 것으로 한다. 그리고 영농일지도 채팅을 통해 얻어 지는
정보를 분류해서 영농일지가 작성이 될 수 있도록 한다"* · I-3 §3(질의 자체가 관찰) · I-5 §5(화면은
원장을 직접 열지 않는다).

## 2. 새 목록은 언제 생기나

작목을 추가하거나 계획이 생길 때 — `ingest/subjects.add`. 작목 이름은 사전(`names/resolve`)을
거친다: 정본·이명이면 정본명으로, **모호하면 되묻고, 없으면 후보로 적어 두고 등재를 청한다**(추측
금지). **U-14(2026-09-19)**: 없는 이름은 `names/candidates` 후보 원장에 자동으로 쌓이고, `/improve`
의 '작목 이름 후보' 표에서 발행자가 정본명·이명 종류를 넣어 승인하면 정본 CSV 에 한 줄이 붙고 사전이
다시 읽혀 다음 새 채팅부터 통한다. 승인·거부는 사람만.
파종 전이면 `status=계획`, `anchor` 없음. 격자 단위는 있으면 붙고 없으면 안 붙는다(판단 불가(지식)).
채팅에서 파종·정식 사건을 확인하면 기준점이 들어가고 `재배 중`이 된다.
