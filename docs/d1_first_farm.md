## 4. 이 결정이 바꾸는 것

### 4-1. 시간축 — 단계 2B 를 시즌 중에 한다
```
계획   T 이전에 첫해 넷(수확기 예측 · 달력 경보 · 방제력 · 예찰)이 서 있어야 한다
실제   T + 24. 작물은 이미 자라고 있고 첫 수확이 몇 주 뒤다
처방   이번 시즌 = 관찰 · 기록 · 영상 시즌. 첫해 넷은 시즌 중 병행 — 되는 것부터
```

첫해 넷 중 지금 서는 순서:

| 값 | 지금 상태 | 막는 것 |
|---|---|---|
| ② 달력형 위험 경보 | 격자 칸 비어 있음 → **판단 불가(지식)** | M-9 쪽파 격자(회복 불가 칸부터) |
| ① 수확기 예측 | 기준점 확보. 격자 칸(파종 후 일수) 비어 있음 → **판단 불가(지식)** | M-9 + 기상 원천(D-5) |
| ④ 광역 예찰 | 원천 키 없음 → **판단 불가(데이터)** | D-5 |
| ③ 표준 방제력 + 보정 | 유기 갈래라 관행 방제력은 해당 없음. 유기 자재 갈래 격자 필요 | M-9 |

**첫 실질의의 형태가 이미 보인다** — "쪽파 언제 수확하나"는 I-1 판별 순서상 **판단
불가(지식)** 이지 판단 불가(데이터)가 아니다. 파종일은 있다. 격자가 없다. 이것이 "우리가
아직 안 만들었다"의 첫 사례이고, 순서를 뒤집어 "입력하면 된다"고 말하면 안 되는 이유다.

### 4-2. 몰 — 첫 상품 = 쪽파 × 가을 작기
- 영상: 생육 중(T+24)이라 **지금이 첫 촬영 시점**이다. 격자 "촬영 시점" 칸이 비어 있어도
  파종 후 생육 영상은 찍어 둔다 — 1층 사실은 나중에 칸에 맞춘다.
  반입 경로(2026-09-18): 폰 카메라 폴더 → PC 동기화 폴더(D-12) → 화면 `/media` 에서 재배 단위
  `p001-jjokpa-2026f` 로 등록. 촬영 시각은 메타에서, 없으면 입력. 부트스트랩 §1b.
- 용도(자가/판매/몰 납품)와 면적이 원문에 없다 — 텃밭 규모의 몰 납품 여부는 **D-8**.
- 저장성 낮음 → 예약 판매(D-3)가 있다면 수확 직전 창이 짧다.

### 4-3. 미해결이 움직인 것
- U-1 여름배추 고랭지(괴산 실태): 첫 필지가 괴산 연풍이라 **실태를 직접 볼 수 있게 됐다**.
  고도는 좌표에서 계산.
- U-12 예비농: 첫 농가가 기존농이라 보류 유지.

## 5. 입력 대기 (필지 고정 정보 I-3 §1 — 원문에 없는 것)

| 항목 | 누가 | 왜 지금 |
|---|---|---|
| 토양검정 성적서 값(pH · EC · 유기물 · 유효인산 · K/Ca/Mg) + 채취일 | 농가 | `soil_chem` parcel 해상도의 실체 |
| 면적 · 용도 · 몰 납품 여부 | 농가(D-8) | 몰-B 상품 성립 |
| 좌표(또는 지번 → 좌표 변환) | 외부 원천 또는 농가 | 일장 · 고도 · 기상 관측소 매칭 |
| 종구 출처 · 품종(있다면) | 농가 | D 품종 보정 — 없으면 상대 추정(낮은 등급) |
| 관수 유무·방식 · 배수 · 경사 · 미기상 3문항 · 야간 조명 | 농가 | 수분 · 병해충 필지 보정 |
| 인증서(법정 인증 여부) | 농가 | "유기농 포장"이 법정 인증인지 관리 방식인지 — 표기 규칙(몰-F)에 걸림 |
| 파종 후 사건(관수 · 제초 · 자재) | 농가 | 사건 원장의 첫 레코드들 |

입력은 **스키마(M-6)가 서기 전에는 이 문서의 표에 적는다** — 두 벌이 되지 않도록, 스키마가
서면 이 표를 첫 레코드로 옮기고 이 표는 "옮김"으로 표시한다.

## 6. 트리 개정 트리거

트리 자기 고백: *"첫 농가가 정해지면 C~F 의 상당 부분이 바뀔 것."* 바뀐 것을 여기 적는다
(2026-09-18 시점):

- C: 첫 배정 완료(§3). 축은 늘지 않았다 — 좋은 신호(U-6).
- D: 단위 = 쪽파 × 가을 작기. 촬영 시점 칸이 시즌 중 소급 입력을 허용해야 한다(신규 요구).
- E: `anchor` · `cert` 확보. `soil_chem` 이 첫 사례부터 parcel 해상도 — I-2 의 district 조건
  동반 규칙은 이번 시즌에는 안 쓰인다(두 번째 농가부터).
- F: 첫 실질의가 판단 불가(지식)로 예측됨(§4-1).
- M: T 지남 → 재계획(§4-1). 마일스톤 문서 §0b 로.
