# I-1 — 3층 산출의 종류 (8종)

**무엇을 지키려는가**: 4층(전달)이 받는 것은 이 목록의 봉투 하나뿐이다. 이 목록에 없는
형태로는 화면에 갈 수 없고, 목록에 있는 형태는 반드시 이 봉투를 채워야 한다.

작성 2026-09-18. 대장 I-1. 근거: 평가서 §4 #1 · §6-3.

> 정정: 평가서 §4 #1 은 "7종"이라 썼는데 나열은 8개였다(세는 실수). **8종**이 맞다.

## 0. 가정 (D-1 · D-2 미확정)

| 가정 | 영향 |
|---|---|
| 첫 작목은 기준점이 농가 행위(정식일)인 일년생 | 판단 불가(데이터)의 첫 사례가 "정식일 미입력"이 된다 |
| 첫 시즌 판정은 소비자 비노출 | 봉투에 `consumer_visible` 필드를 두되 첫 시즌 값은 전부 false |

## 1. 공통 봉투 (전 산출 공통)

| 필드 | 뜻 | 비고 |
|---|---|---|
| `kind` | 아래 8종 중 하나 | 화면은 이 값으로 형태를 가른다(M-13 관문) |
| `decision_id` | 어떤 결정에 대한 산출인가 | 3층 등록 결정의 id |
| `subject` | 필지 × 재배 단위 | 몰 상품 키와 같다 |
| `as_of` | 판정 시각 | |
| `inputs` | 쓰인 축 목록 — 각각 관측 시각 · 출처 · 해상도 | 1층 3요건을 그대로 실어 나른다(H G2) |
| `missing` | 필요했는데 없던 축 | 판단 불가(데이터)에서만 비어 있지 않다 |
| `caps` | 상한 제약(예측을 무효화하는 사건) | 오차 폭으로 표현 안 되는 것 |
| `revisit_at` | 재판정 예정 | 답이 바뀌는 게 정상인 결정만 |
| `consumer_visible` | 소비자 노출 가능 여부 | D-2 결정 전 false 고정 |

**규칙**: 봉투에 1·2층 원본 값을 싣지 않는다 — `inputs` 는 *무엇을 썼는지*이지 값이
아니다(4층 격리). 값이 필요하면 **사실 인용**(§2-3)이라는 별개 산출로 낸다.

## 2. 8종

### 2-1. 판단함
값 + **신뢰 등급** + **오차 폭**. 신뢰 등급은 쓰인 축 중 **가장 약한 축**의 등급(E 3분류:
계산 > 관측 > 추정). 오차 폭은 수치(예: 수확 예상일 ±3일)이고 등급과 별개다 — 등급이
"추정"이면 오차 폭이 좁아도 좁다고 믿지 않는다.

### 2-2. 선택지 + 대가
고정 결정(0~3단계)과 "통제 가능" 축의 산출. **순위를 매기지 않는다** — 후보 목록과 각
후보의 대가(비용 · 되돌림 가능성 · 전제 조건)만 낸다. 결정은 농가. 농가의 선택은
입력 5종의 **결정**으로 돌아온다(I-3).

### 2-3. 사실 인용
판단 없이 1층 사실을 전달한다(시세 · 예찰 원문 · 평년값). 3층을 거치는 이유는 하나 —
**인용 대상이 1층 3요건을 만족하는지 확인**하는 것이 판정이다. 요건이 빠진 사실은
인용되지 않는다. 출처 · 관측 시각 · 해상도가 인용문에 붙는다.

### 2-4. 판단 불가 — 데이터
필요 축이 비어 있다. `missing` 에 축 목록과 **누가 채울 수 있는가**(농가 입력 / 외부
원천 / 시간 경과)를 싣는다. 사용자에게: *"이것을 채우면 답이 나온다."*

### 2-5. 판단 불가 — 지식
격자 칸이 "아직 안 채움"이다. 데이터를 채워도 답이 안 나온다. 사용자에게: *"우리가 아직
안 만들었다."* 내부적으로 **대장 등재 트리거**(칸 2 — 구조적 위험).

### 2-6. 해당 없음
이 작목 · 이 단계 · 이 조건에는 이 결정이 적용되지 않는다(격자 칸 "해당 없음" 또는
조건 불일치). 아무리 채워도 바뀌지 않는다.

### 2-7. 예측 불가
조건 자체가 없다(통제 · 예측 불가 축). 판단하지 않고 **회복 경로**만 낸다.

### 2-8. 답하지 않음
정책적으로 답하지 않는 영역 — 예측이 대상을 바꾸는 것(가격). 몰 가격은 계약이라
이 종류가 아니라 **DSS 대상 밖**이다(3층에 결정이 등록되지 않는다).

## 3. 판별 순서 (한 결정에 대해)

```
결정이 3층에 등록돼 있는가        아니오 → (산출 없음 — DSS 대상 밖)
정책상 답하지 않는가              예   → 답하지 않음
조건이 이 결정에 해당하는가        아니오 → 해당 없음
격자 칸이 채워져 있는가            아니오 → 판단 불가(지식)
필요 축이 전부 있는가              아니오 → 판단 불가(데이터)
축이 통제·예측 불가인가            예   → 예측 불가
결정이 고정/통제 가능 결정인가     예   → 선택지 + 대가
판단이 필요 없는 사실 전달인가     예   → 사실 인용
                                  그 외 → 판단함
```

순서가 계약이다 — 판단 불가(지식)가 판단 불가(데이터)보다 **앞**이다. 뒤집으면 "입력하면
된다"고 농가에게 말해 놓고 입력해도 답이 안 나온다.

## 4. 검사 (M-5 에서 코드로)

- 봉투 스키마에 1·2층 값 필드가 없다(거부).
- 8종 각각의 표본이 4층 조립 함수를 통과한다(통과).
- 판별 순서를 뒤집는 주입(지식/데이터 순서 교환)에 검사가 깨진다.
