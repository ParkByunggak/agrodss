## 1. 로컬 준비 (2026-09-18 갱신 — 원격이 생겼다)

원격 `https://github.com/ParkByunggak/agrodss` 에 첫 커밋(1110d16)이 있다. 로컬은 한 줄이다.

```
git clone https://github.com/ParkByunggak/agrodss.git D:\agrodss
```

vela 원격은 **추가하지 않는다**. vela 는 경험이지 원격이 아니다 — 남겨 두면 다음 사람이
코드를 당겨 온다(이식 폐기 결정). 필요한 문서는 전부 이 저장소 `docs/` 에 있다.

PowerShell 5.1 의 `>` 는 UTF-16 으로 쓴다 — 한글 파일을 리다이렉트로 만들지 않는다.

**내부 화면(M-13)**: `run_frontend.bat` 를 더블클릭하면 의존성 설치 후 `http://127.0.0.1:8765/`
가 브라우저 새 창에 열린다(첫 페이지 = 대장). 문서를 고치고 새로고침하면 그대로 보인다.
루프백 전용이라 외부에서 접근할 수 없다(D-6). 포트는 `AGRODSS_FRONTEND_PORT` 로 바꾼다.

관문: `python -m pytest` (루트에서). 세션 마감 전 반드시 전체 실행.

## 1b. 영상 반입 — 휴대폰 ↔ PC 동기화 (I-7, 발행자 2026-09-18 "동기화되어야 한다")

외부 배포 금지(D-6)라 앱이 폰에 노출되지 않는다. 대신 **폰 카메라 폴더가 PC 로 동기화되는 폴더를
앱이 감시**한다. 앱은 그 폴더를 읽기만 하고 등록 시 **복사**한다 — 옮기면 폰에서도 지워진다.

| 폰 | 동기화 도구(폰에서 켠다) | PC 쪽 폴더(예) |
|---|---|---|
| 안드로이드(삼성) | OneDrive 앱 → 카메라 업로드 | `C:\Users\<이름>\OneDrive\사진\카메라 앨범` |
| 안드로이드 | 구글 드라이브/포토(데스크톱 앱) | `G:\내 드라이브\…` 또는 포토 백업 폴더 |
| 아이폰 | Windows 용 iCloud → 사진 | `C:\Users\<이름>\Pictures\iCloud Photos\Downloads` |
| 클라우드 없이 | Syncthing(폰·PC 설치, 같은 Wi-Fi) | 내가 정한 폴더 |

어느 도구든 **D-12(발행자 결정)** 로 하나를 정한 뒤, `D:\agrodss\.env` 에 한 줄:

```
AGRODSS_WATCH_DIRS=C:\Users\<이름>\OneDrive\사진\카메라 앨범
```

(여러 폴더는 `;` 로 구분.) `run_frontend.bat` 를 다시 켜고 `http://127.0.0.1:8765/media` 를 열면
폴더의 영상이 "등록 대기"에 뜬다. 촬영 시각·해상도는 MP4 메타에서 자동으로 읽고, 없으면 직접
넣는다 — **시각이 없으면 등록되지 않는다**(대리값 금지). 등록되면 `data\media\<재배단위>\` 로
복사되고 `data\media\index.jsonl` 에 1층 레코드가 남는다. 영상은 git 에 올라가지 않는다.

동기화 없이 급할 때: 파일을 `D:\agrodss\data\media\inbox\` 에 넣어도 같은 화면에 뜬다(이쪽은 옮김).
