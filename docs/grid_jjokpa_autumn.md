# 격자 — 쪽파 × 가을 (정본: `data/grid/jjokpa_autumn.json`)

**이 문서는 생성물이다.** 고치려면 JSON 을 고치고 `python scripts/build_grid_doc.py` 를 돌린다.

- 기준점: **파종(종구)** (0일) · 작형 결정권: season · 출처: 추론 초안 2026-09-18 (농가 상식 수준). 농사로 쪽파 재배기술 정보와 대조 대기(M-15 ③). 발행자 검토 대기 · 확신 중
- 검증: 통과 · 완성도: 값 62 · 해당없음 4 · 미채움 0
- 회복 불가 칸부터 채웠다(M-7 원칙). 시비량 등 수치 칸은 정본(토양검정 값 · 공공 처방 기준)이 도착하기 전에는 비워 둔다.
- 품종 보정: 시간 이동 해당없음 · 칸 덮어쓰기 0건 · 쪽파는 품종 분화가 낮다(crop_axes). 종구 출처가 '재래'면 보정 없음. 대목 자리는 목본용 — 해당 없음
