등록부는 규칙·필요 축·금지 축 중 하나라도 없으면 등록을 거부한다. 결정의 필요 축은 격자 칸의
판정 축 안에 있어야 하고, 칸의 금지 축은 결정도 금지해야 한다(검사).

## 판별 순서 (I-1 §3 그대로)

```
해당하는가          격자 단위 · 수확 칸 없음 → 해당 없음
격자 칸 채워졌는가   window 없음 → 판단 불가(지식)   ← 데이터보다 먼저
필요 축 있는가       anchor 없음 → 판단 불가(데이터) missing=[anchor, 농가]
                    → 판단함
```
