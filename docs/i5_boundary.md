# I-5 — 몰 ↔ DSS 경계 필드 목록 · 양방향 검사 설계

**무엇을 지키려는가**: DSS 가 그 농가의 판매·재고를 정확히 아는 구조에서, 일차 기능(차이
탐지)이 납품 최적화로 휘지 않게 한다. 규칙이 아니라 **스키마**로 막고, 막는 검사와 흐르는
검사를 짝으로 둔다.

작성 2026-09-18. 대장 I-5 → M-3. 근거: 평가서 §6-3 · 몰 트리 몰-H · CLAUDE.md 절대 제약.

## 1. 필드 목록

### 1-1. 몰 → DSS

| 필드 | 방향 | 들어가는 곳(I-3) | 조건 |
|---|---|---|---|
| 영상(파일 · 촬영 시각 · 필지 · 해상도) | **허용** | 관찰(영상) | 메타 3요건 없으면 진입 불가 |
| 수확량 | **허용** | 사건(수확) 결과 기록 | `source=mall:settlement` |
| 품질 등급 | **허용** | 사건(납품) 결과 기록 | 동상 |
| 반품 사유 — 품질 갈래 | **허용** | 사건(납품) 결과 기록 | 배송·변심 갈래는 오지 않음 |
| 납품 계획일 | **조건부** | 계획 | `source=farmer` 일 때만. `source=mall:*` 이면 거부 |
| 재고 | **금지** | (자리 없음) | |
| 주문 잔량 | **금지** | (자리 없음) | |
| 판매 속도 · 조회수 | **금지** | (자리 없음) | |
| 정산액 · 단가 | **금지** | (자리 없음) | 가격은 DSS 대상 밖 |
| 리뷰 · 평점 | **금지** | (자리 없음) | 수요 신호 |
| 몰 수요 예측 | **금지** | (자리 없음) | |

### 1-2. DSS → 몰

| 필드 | 방향 | 조건 |
|---|---|---|
| 촬영 시점 알림(격자 칸) | **허용** | |
| 산출 봉투(I-1) — `consumer_visible=true` 인 것만 | **조건부** | D-2 결정 전에는 전부 false → 실질 0건 |
| 필지 상세(주소 · 검정값 · 좌표) | **금지** | PII |
| 1·2층 원본 값 | **금지** | 4층 격리 — 봉투의 `inputs` 는 이름뿐 |

## 2. 두 겹 방어

```
1겹  스키마   금지 필드는 3층 판단 입력 스키마에 **자리가 없다**      (I-3 §6)
2겹  검사     자리가 생기면 깨지고 · 허용 필드가 안 흐르면 깨진다      (아래)
```

1겹만 있으면 다음 사람이 "편의상" 필드를 추가한다. 2겹만 있으면 검사가 안 도는 회차에
새는다(VELA: 가드 창).

## 3. 양방향 검사 설계 (M-3 에서 코드로)

### 3-1. 거부 검사 — 금지 필드가 없다

```
대상   3층 판단 함수의 입력 스키마(마이그레이션이 원본)
판정   금지 필드 id 집합 ∩ 스키마 필드 집합 = ∅
주입   스키마에 `stock` 필드를 추가한 상태로 돌리면 실패해야 한다
```

이름 매칭만 하면 `inventory_qty` 같은 우회 이름을 못 잡는다. 그래서 **허용 목록 방식**을
짝으로 둔다 — 스키마 필드는 허용 목록(1-1 허용·조건부 + 입력 5종의 고유 필드)의 부분집합.
금지 목록은 문서용, 허용 목록이 검사용.

### 3-2. 통과 검사 — 허용 필드가 흐른다

```
대상   몰 정산 레코드 → DSS 사건(수확·납품) 변환
판정   표본 정산(수량·등급·반품 사유 품질) → 사건 레코드에 세 값이 도착하고 source=mall:settlement
주입   변환에서 반품 사유 매핑 한 줄을 지우면 실패해야 한다
```

VELA N-147 형태를 여기서 막는다 — *"관문은 서 있는데 값이 안 도착한다."*

### 3-3. 출처 검사 — 조건부 필드

```
대상   계획(납품 계획일)
판정   source=farmer → 진입 / source=mall:demand → 거부
주입   거부 분기를 지우면 실패해야 한다
```

### 3-4. 위치 검사 — 산출 레벨 말미 1회

경계 게이트는 경로마다가 아니라 **3층 진입 직전 1회**다. 검사는 호출형뿐 아니라 **위치**를
본다(VELA 규율: 차단 지점이 주입 지점보다 앞이면 무효) — 게이트 호출이 모든 입력 병합
뒤에 있는지. 구역(함수 본문)을 잘라 검사하고 문자 창·줄 번호로 고정하지 않는다.

## 4. 검사의 검사

네 검사 각각에 위 "주입" 을 실제로 넣어 **실패를 본 뒤** 배치한다. 주입은 원 결함을
완전히 재현해야 한다(부분 주입은 다른 가드에 가린다). `failed` 와 `error` 를 함께 센다 —
주입본이 SyntaxError 면 0 failed 로 읽힌다.

## 5. 이 경계가 M-13 화면에 요구하는 것

화면은 4층이다. 화면이 받는 데이터 소스는 **산출 봉투와 몰 화면 데이터 둘**이고, 화면
코드가 DSS 1·2층 저장소를 직접 읽는 경로가 없어야 한다. 이것도 M-3 의 검사 하나다
(프론트엔드 코드에서 원장 접근 import 가 없다 — 배선 부재를 결정으로 고정).
